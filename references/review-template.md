# 分层复盘手册（自动记账 + 里程碑复盘）

本文件是 `lili-ai-coach` 复盘机制的细化模板。面向 agent，中立第三人称。与 SKILL.md 🪞 复盘与迭代模式配套，不重复。

> **用户输出规范（强制）**：输出给 lili酱 时禁止说「复盘 / 迭代 / playbook / 上下文」等词，改说「咱们回头看一眼哪顺哪卡」「把顺手的经验存下来下次直接用」。具体见 SKILL.md 术语转译表。

## 1. 自动记账（微型复盘，每次服务结束自动跑）

查理每完成一次服务（挖需求 / 写四件套 / 拆步骤 / 卡点救援 / Token 优化 任一种），**静默**把一笔追加写入本项目的 `lili-coach-log.md`（磁盘文件，不进仓库、不每轮加载）。lili酱 无需任何操作。

追加格式（每笔一行块）：
```
## [日期] <本次服务类型> · 1 句话总结
- 核心问题：<lili酱 这次卡在 / 想清楚的是什么>
- 解决方法：<查理带她用的那一招>
- 提效价值：<她原话或一句话：这次省了哪步 / 想清了啥>
```
> 不写过程流水，只写「问题 / 方法 / 价值」三件事，便于以后检索。

## 2. 里程碑复盘（累计 5 次或主动触发）

满足以下任一即进入深度复盘（不触发 scope 护栏）：
- 账本累计 **5 笔**；
- lili酱 主动说「帮我想想这次顺不顺」「这格别扭想改」「咱们回头看一眼」。

按四维度引导（每维一句话，别考她）：
1. **走偏没**：这一阶段哪步走偏了？为什么会偏？（帮她长出「提前觉察」的直觉）
2. **顺手不**：哪些方法用着顺？哪些没用？（留下好用的，丢掉别扭的）
3. **怎么优化**：接下来的协作流程可以怎么调？（落到下次的「项目四件套 / 步骤清单」）
4. **存一条**：沉淀 1 条「下次直接能用」的经验，写进账本「💡 常用经验」区。

里程碑复盘结论 → 喂回：①改 workflow 卡别扭的那格 ②微调 PTCF PRD ③新需求进 backlog。闭环：需求→四件套→步骤→执行→复盘→迭代。

## 3. 防膨胀（R7）

- 账本**追加式**增长；每累计 **~5 笔复盘** 或超 **~40 行**，查理做一次 compact：
  - 生成 `lili-coach-log.v2.md` 精简版（只留「问题/方法/价值」结论 + 「💡 常用经验」）；
  - 旧 raw 归档为 `lili-coach-log.archive.md`，不删。
- 永不无界增长；精简后只保留可复用结论，删冗余对话细节。

## 4. 与 Phase C「📝 复盘记录」格的关系

同一件事的两层：那格是 workflow 卡内的轻量入口，本手册是跨整个协作的标准化记账与归档。整合不重复——卡内别扭格的改动，同时记一笔到账本。
