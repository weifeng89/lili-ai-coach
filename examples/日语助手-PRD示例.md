# 示例：用「日语学习助手」跑通里程碑1（柔性入口 + MVP）

> 本文件演示 `lili-ai-coach`（查理）针对 lili酱 真实项目「日语学习助手」走完 需求挖掘 → PTCF PRD → workflow 设计 → 收口(感知提效) 的闭环。注意：这是**示范输出**，lili酱 实际用时由她本人确认每一步。
> 本例从 **A 需求挖掘** 进（lili酱 带着模糊想法来）；若她带着现成 PRD 来，查理会按「入口路由」直接进 C（见 `examples/沟通卡点-查理陪练示例.md` 不分强弱）。

---

## Phase A · 需求挖掘（节选）

**lili酱**：「我想做个练日语的东西。」

**查理（frontier 轮次，带推荐，3–5 问）**：
```
❓ Q1 - 你主要想练哪块？
  ➡️ 我的建议：听写（听一句写一句，最能暴露弱点）
❓ Q2 - 你希望它在哪用？
  ➡️ 我的建议：微信里（你日常就在用，不用开新 app）
❓ Q3 - 你最怕卡在哪一环？
  ➡️ 我的建议：错了没人帮指出（所以纠错高亮是关键）
❓ Q4 - 你打算每天练多久？
  ➡️ 我的建议：10 分钟通勤碎片时间（决定 workflow 的「触发」频率）
```

**lili酱**：「听写、微信里、最怕错了不知道哪错、通勤 10 分钟。」

**真伪需求探测 + pattern 识别**：
- lili酱 原话：「要个超酷的打卡日历大屏。」→ 追问「做成了解决啥？」→ 「其实就是想看到自己每天学没学。」→ **⚠️ 伪需求（手段）**（pattern：前面也提过「页面要炫」）→ 真需求 = 每日学习可视化；最小替代 = 一个每日状态 + 数字，不做大屏。
- 「听写 + 纠错高亮」→ **✅ 真需求**（复述确认：lili酱 用自己的话说「就是发语音我写、写错你帮我圈出来」，与推断一致 → 确认）。

---

## Phase B · PTCF PRD（MVP 优先）

```markdown
# 日语学习助手 PRD（PTCF）

## P · 画像
- 为谁做：lili酱 自己（零基础、非技术、懂音乐）
- 使用者：每天通勤想练 10 分钟日语的人

## T · 任务（MVP：只保留验证真需求必需的功能）
- 核心：发一段日语语音/句子 → 查理让我听写 → 我写完后标出错误并高亮
- 价值：把「不知道错哪」变成「错处一目了然」
- 待办清单（暂不做）：打卡日历大屏、社交分享、AI 语音陪聊

## C · 约束
- 环境：微信对话里用（WorkBuddy）
- 已有资源：已订阅模型、Obsidian 知识库
- 限制：国内可直连、免费、不写代码

## F · 验收
- 交付物：一段对话式听写 + 纠错高亮结果
- 标准：
  - [ ] 我发语音/句子后，查理给听写任务
  - [ ] 我提交后，查理标出错处并高亮
  - [ ] 错的类型（假名/时态/助词）用一句话说明
```

**完整度检查**：4 段齐 + 验收齐 → **通过**。缺口：原「大屏」已转「排除项 / 待办清单」。

> 排除项：原计划做打卡日历大屏，实为手段，已改为「每日学习状态 + 数字」最小替代，并移入待办清单（MVP 优先，不分散 lili酱 决策）。

## Phase C · workflow 设计

```markdown
# 日语学习助手 Workflow 卡

## 🎯 触发
每天通勤，打开微信对查理说「来段听写」

## 🪜 步骤
1. 你发「听写」→ 查理给一句日语（带朗读）
2. 你听写打字发回
3. 查理比对 → 错处高亮 + 一句说明
4. 你改对，查理给下一句

## 🔀 决策点
- 在 步骤3：错太多 → 选「降难度」还是「重复本句」？由你定

## 📦 产出
一份带高亮的听写结果 + 今日错题小记

## 🔁 回流
错题小记自动进 Obsidian「日语错题」页，下次先复习

## 🛠 工具 / Skill（可选，由运行时 Agent 判断）
- 步骤1 可能用到「语音朗读 / 文本转语音」类工具
- 步骤3 可能用到「日语语法检查」类 skill
- 是否触发由 lili酱 当时用的 Agent（WorkBuddy/Codex/Hermes）自己决定，本卡不写死

## 📝 复盘记录
（跑过几轮后回来填：哪格别扭、改了啥）
```

**查理对 lili酱 说**：「**这就是 workflow 的结构**——触发→步骤→决策点→产出→回流。你以后和 AI 练日语就按这个走，步骤名、比喻你都能自己改。哪步可能用到的工具我也标了，但具体用不用、用哪个，是你当时那个 Agent 自己判断的，不是我替它定死的。」

## Phase D · 收口 + 感知提效

**查理**：「对比你一开始只说『做个练日语的东西』，这次 AI 帮你在哪几步省了力 / 想清楚了什么？」

**lili酱（原话记录）**：「我本来只想搞个大屏，被你问出其实我就想看自己学没学；还有听写到底要『错处高亮』我之前根本说不清，现在清楚了。省了我瞎做一大屏的劲。」

**查理**：「里程碑1 完成🎉。大屏我记在待办清单，等这一步你真跑顺了咱们再看。先别加别的，把这一件做扎实。」
